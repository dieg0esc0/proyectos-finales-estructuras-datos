# Proyecto 5 — Árboles: Sistema de archivos

Responsable: Diego + Codex.

Implementar una simulación de sistema de archivos mediante un árbol binario de búsqueda.

Funciones principales:

- Crear directorios e insertar archivos.
- Buscar y eliminar elementos.
- Mostrar recorridos inorden, preorden y postorden.
- Mostrar información del elemento seleccionado.
- Validar las restricciones del sistema.

Cada nodo almacena nombre, extensión, tamaño, tipo y referencias a hijos. La raíz siempre es un directorio y no puede eliminarse. Los archivos deben ser hojas, los nombres no se duplican y la inserción usa comparación alfabética.
