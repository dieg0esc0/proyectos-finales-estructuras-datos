# Instrucciones para Codex y colaboradores

## Alcance

Este repositorio contiene seis proyectos académicos independientes de Estructuras de Datos y Algoritmos. Trabajar únicamente en el proyecto asignado y evitar cambios en las carpetas de otros responsables.

## Lenguaje y ejecución

- Usar Java.
- Mantener una aplicación de consola clara y fácil de demostrar.
- No añadir dependencias externas sin justificarlo.
- Incluir un punto de entrada `Main.java` por proyecto.
- Separar las clases por responsabilidad.
- Validar entradas y mostrar mensajes comprensibles.
- Documentar clases, métodos y decisiones relevantes.
- Evitar código generado innecesariamente complejo.

## Calidad requerida

Antes de declarar terminado un proyecto:

1. Compilar todo el código.
2. Probar cada requerimiento funcional.
3. Cubrir entradas válidas, inválidas y casos límite.
4. Actualizar el README del proyecto.
5. Añadir evidencias de ejecución.
6. Confirmar que el UML coincide con el código.
7. No modificar ni borrar entregas de otros integrantes.

## Flujo Git

- Una rama por proyecto: `proyecto/05-arboles`, `proyecto/06-grafos`, etc.
- Commits pequeños y descriptivos.
- No subir archivos compilados, configuraciones del IDE ni credenciales.
- Abrir pull request hacia `main` para revisión.
